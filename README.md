# Soyabean Mandi Price Forecasting

AI-Based Short-Term Soyabean Mandi Price Forecasting and Market Stress Analysis using AGMARKNET Data.

## Features
- Historical price analysis
- Forecast visualization
- Model comparison
- Streamlit dashboard

## Models Used
- Linear Regression
- XGBoost
- Prophet

## Dataset
AGMARKNET-derived Maharashtra mandi dataset (2020–2024)
