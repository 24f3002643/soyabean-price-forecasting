# Soyabean Mandi Price Forecasting

AI-Based Short-Term Soyabean Mandi Price Forecasting using historical agricultural market data from Maharashtra mandis.

## Features

* Historical soyabean price analysis
* Interactive Streamlit dashboard
* Recursive 7-day price forecasting
* Forecast visualization
* Model comparison and evaluation

## Models Used

* Linear Regression
* XGBoost Regressor
* Prophet

## Dataset

Agricultural mandi dataset obtained from Kaggle containing Maharashtra market records from 2020–2024.

Dataset Link:
https://www.kaggle.com/datasets/sachinjoshisgbau/agri-market-dataset-1/data

## Tech Stack

* Python
* Pandas
* Scikit-learn
* XGBoost
* Prophet
* Streamlit
* Matplotlib
